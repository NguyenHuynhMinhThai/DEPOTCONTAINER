PHẦN 1: TỔNG QUAN KIẾN TRÚC
================================================================================

Project DEPOTCONTAINER dùng .NET 10 + Entity Framework Core 9 (Pomelo MySQL),
chia theo kiến trúc 3-Tier:

   HTTP Request
       │
       ▼
   ┌─────────────────────────────────────────┐
   │  Controllers/Api/                       │  ← Tầng Presentation (API)
   │  - ContainersController                 │
   │  - BlocksController                     │
   │  - MovementsController                  │
   │  - LineOperatorsController              │
   └─────────────────────────────────────────┘
       │ gọi
       ▼
   ┌─────────────────────────────────────────┐
   │  Services/                              │  ← Tầng Business Logic
   │  - ContainerService                     │
   │  - BlockService                         │
   │  - ContainerMovementService             │
   │  - ReleaseOrderService                  │
   │  - LineOperatorService / CustomerService│
   └─────────────────────────────────────────┘
       │ gọi
       ▼
   ┌─────────────────────────────────────────┐
   │  Repositories/                          │  ← Tầng Data Access
   │  - GenericRepository<T>                 │
   │  - Specific Repositories                │
   │  - UnitOfWork (giao dịch)               │
   └─────────────────────────────────────────┘
       │ gọi
       ▼
   ┌─────────────────────────────────────────┐
   │  DepotDbContext (Entity Framework Core) │  ← ORM, kết nối MySQL
   └─────────────────────────────────────────┘
       │
       ▼
   ┌─────────────────────────────────────────┐
   │  MySQL Database (depotdb)               │
   └─────────────────────────────────────────┘

Quy trình: Controller nhận request → gọi Service xử lý nghiệp vụ → gọi
Repository truy vấn DB thông qua EF Core → trả về DTO cho Client.

Đăng ký dịch vụ (DI) trong Program.cs (Scoped - 1 instance / request):
   - IUnitOfWork → UnitOfWork
   - IContainerService → ContainerService
   - IBlockService → BlockService
   - ILineOperatorService → LineOperatorService
   - ICustomerService → CustomerService
   - IContainerMovementService → ContainerMovementService
   - IReleaseOrderService → ReleaseOrderService

Singleton: DepotConfigManager, InMemoryCache.

BƯỚC 1: BaseEntity - Lớp cha cho mọi entity
--------------------------------------------------------------------------------
File: Models/Entities/BaseEntity.cs

```csharp
public abstract class BaseEntity
{
    [Key][Column("id")]
    public int Id { get; set; }

    [Column("created_at")]
    public DateTime CreatedAt { get; set; } = DateTime.UtcNow;

    [Column("updated_at")]
    public DateTime? UpdatedAt { get; set; }

    [Column("is_deleted")]
    public bool IsDeleted { get; set; } = false;
}
```

Mục đích: cung cấp 4 trường chung cho mọi bảng (Id, CreatedAt, UpdatedAt,
IsDeleted). IsDeleted dùng cho soft-delete (xóa mềm), kết hợp với global query
filter trong DbContext để tự động loại trừ khi truy vấn.

```csharp
public class LineOperator : BaseEntity
{
    [Required][MaxLength(4)][Column("owner_code")]
    public string OwnerCode { get; set; } = string.Empty;   // VD: "CMA"

    [Required][MaxLength(200)][Column("name")]
    public string Name { get; set; } = string.Empty;        // VD: "CMA CGM"

    [MaxLength(50)][Column("tax_code")]
    public string? TaxCode { get; set; }

    [MaxLength(500)][Column("address")]
    public string? Address { get; set; }

    [MaxLength(20)][Column("phone")]
    public string? Phone { get; set; }

    [MaxLength(100)][Column("email")]
    public string? Email { get; set; }

    [MaxLength(1000)][Column("note")]
    public string? Note { get; set; }

    // Navigation: 1 LineOperator có nhiều Container
    public virtual ICollection<Container> Containers { get; set; } = new List<Container>();
    // Navigation: 1 LineOperator có nhiều ReleaseOrder
    public virtual ICollection<ReleaseOrder> ReleaseOrders { get; set; } = new List<ReleaseOrder>();
}
```

Quan hệ:
   LineOperator (1) → (n) Container         (qua Container.LineOperatorId, Restrict)
   LineOperator (1) → (n) ReleaseOrder      (qua ReleaseOrder.LineOperatorId, Restrict)

Cấu hình trong DbContext:
   - Index unique trên OwnerCode (mỗi hãng có 1 mã duy nhất)
   - OnDelete Restrict: không cho xóa hãng nếu còn container / lệnh giao

BƯỚC 4: Block - Bãi chứa container
--------------------------------------------------------------------------------
File: Models/Entities/Block.cs

```csharp
public class Block : BaseEntity
{
    [Required][MaxLength(20)][Column("code")]
    public string Code { get; set; } = string.Empty;        // VD: "A", "B", "V-01"

    [Required][MaxLength(100)][Column("name")]
    public string Name { get; set; } = string.Empty;        // VD: "Block A - 20ft"

    [Column("block_type")]
    public BlockType BlockType { get; set; } = BlockType.Physical;

    [Column("max_bays")]
    public int? MaxBays { get; set; }                       // Chỉ dùng cho Physical

    [Column("max_rows")]
    public int? MaxRows { get; set; }                       // Số row trong 1 bay

    [Column("max_tiers")]
    public int? MaxTiers { get; set; }                      // Số tầng xếp chồng

    [Column("max_container_size")]
    public ContainerSize? MaxContainerSize { get; set; }    // 20/40/45 feet

    [MaxLength(500)][Column("description")]
    public string? Description { get; set; }

    [Column("is_active")]
    public bool IsActive { get; set; } = true;

    // Navigation
    public virtual ICollection<Bay> Bays { get; set; } = new();
    public virtual ICollection<Container> Containers { get; set; } = new();
}
```

Block có 2 loại:
   - Physical: có layout Bay → Row → Tier, dùng để xếp container thật.
   - Virtual: block ảo, không sinh layout (vd: block chứa container hư hỏng).

Quan hệ:
   Block (1) → (n) Bay                (Cascade: xóa block → xóa hết bay con)
   Block (1) → (n) Container          (SetNull: xóa block → container.CurrentBlockId = null)

Cấu hình: Index unique trên Code.

```csharp
public class Container : BaseEntity
{
    [Required][MaxLength(11)][Column("container_number")]
    public string ContainerNumber { get; set; } = string.Empty;  // ISO 6346, VD: CMAU1234567

    [Column("container_type")]
    public ContainerType ContainerType { get; set; }             // U=Dry, R=Reefer...

    [Required][MaxLength(10)][Column("iso_code")]
    public string IsoCode { get; set; } = string.Empty;          // VD: 22G1, 45R1

    [Column("size")]
    public ContainerSize Size { get; set; }                      // 20/40/45 feet

    [Column("max_weight")]
    public decimal MaxWeight { get; set; }                       // Trọng lượng tối đa

    [Column("tare_weight")]
    public decimal TareWeight { get; set; }                      // Trọng lượng vỏ

    [Column("manufacture_date")]
    public DateTime? ManufactureDate { get; set; }

    // Foreign keys
    [Column("line_operator_id")]
    public int? LineOperatorId { get; set; }

    [Column("current_block_id")]
    public int? CurrentBlockId { get; set; }                    // Vị trí hiện tại

    [Column("current_bay_id")]
    public int? CurrentBayId { get; set; }

    [Column("current_row_id")]
    public int? CurrentRowId { get; set; }

    [Column("current_tier_id")]
    public int? CurrentTierId { get; set; }

    [Column("condition")]
    public ContainerCondition Condition { get; set; } = ContainerCondition.Normal;

    [Column("category")]
    public ContainerCategory Category { get; set; } = ContainerCategory.CategoryA;

    [MaxLength(1000)][Column("damage_description")]
    public string? DamageDescription { get; set; }

    [Column("is_in_yard")]
    public bool IsInYard { get; set; } = false;                  // true = đang ở trong bãi

    // Navigation
    public virtual LineOperator? LineOperator { get; set; }
    public virtual Block? CurrentBlock { get; set; }
    public virtual Bay? CurrentBay { get; set; }
    public virtual Row? CurrentRow { get; set; }
    public virtual Tier? CurrentTier { get; set; }
    public virtual ICollection<ContainerMovement> Movements { get; set; } = new();
}
```

Cấu trúc Container Number (ISO 6346, 11 ký tự):
   ┌──────────┬──────┬──────────┬──────────┐
   │OwnerCode │ Type │  Serial  │ CheckDig │
   │  (3 chữ) │(1 chữ)│ (6 số)  │  (1 số)  │
   │   CMA    │  U   │  123456  │    7     │
   └──────────┴──────┴──────────┴──────────┘
   Tổng: 4 chữ cái + 7 chữ số = 11 ký tự.

Quan hệ:
   Container (n) → (1) LineOperator   (Restrict)
   Container (n) → (1) CurrentBlock   (SetNull)
   Container (n) → (1) CurrentBay     (SetNull)
   Container (n) → (1) CurrentRow     (SetNull)
   Container (n) → (1) CurrentTier    (SetNull)
   Container (1) → (n) ContainerMovement  (Cascade)

Cấu hình: Index unique trên ContainerNumber.

```csharp
    public string? DriverId { get; set; }
```

3 loại movement:
   - In: Container vào bãi → IsInYard=true, CurrentBlockId=ToBlockId.

   - Internal: Di chuyển nội bộ giữa các vị trí trong bãi.

Quan hệ:
   Movement (n) → (1) Container     (Cascade: xóa container → xóa movement)
   Movement (n) → (0..1) Block      (SetNull: xóa block → ToBlockId = null)
   Movement (n) → (0..1) ReleaseOrder (SetNull)

BƯỚC 12: DepotDbContext - Cấu hình database
--------------------------------------------------------------------------------
File: Data/DepotDbContext.cs

```csharp
public class DepotDbContext : DbContext
{
    // Khai báo 10 bảng (DbSet)
    public DbSet<LineOperator> LineOperators { get; set; }
    public DbSet<Customer> Customers { get; set; }
    public DbSet<Block> Blocks { get; set; }
    public DbSet<Bay> Bays { get; set; }
    public DbSet<Row> Rows { get; set; }
    public DbSet<Tier> Tiers { get; set; }
    public DbSet<Container> Containers { get; set; }
    public DbSet<ContainerMovement> ContainerMovements { get; set; }
    public DbSet<ReleaseOrder> ReleaseOrders { get; set; }
    public DbSet<ReleaseOrderDetail> ReleaseOrderDetails { get; set; }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        base.OnModelCreating(modelBuilder);

        // 1. Enum → int (lưu trong DB dưới dạng số nguyên)
        modelBuilder.Entity<Container>()
            .Property(c => c.ContainerType).HasConversion<int>();
        modelBuilder.Entity<Container>()
            .Property(c => c.Size).HasConversion<int>();
        // ... các enum khác tương tự

        // 2. Unique indexes
        modelBuilder.Entity<LineOperator>()
            .HasIndex(l => l.OwnerCode).IsUnique();
        modelBuilder.Entity<Customer>()
            .HasIndex(c => c.TaxCode).IsUnique();
        modelBuilder.Entity<Block>()
            .HasIndex(b => b.Code).IsUnique();
        modelBuilder.Entity<Container>()
            .HasIndex(c => c.ContainerNumber).IsUnique();
        modelBuilder.Entity<ReleaseOrder>()
            .HasIndex(r => r.OrderNumber).IsUnique();

        // Composite unique indexes
        modelBuilder.Entity<Bay>()
            .HasIndex(b => new { b.BlockId, b.BayNumber }).IsUnique();
        modelBuilder.Entity<Row>()
            .HasIndex(r => new { r.BayId, r.RowNumber }).IsUnique();
        modelBuilder.Entity<Tier>()
            .HasIndex(t => new { t.RowId, t.TierNumber }).IsUnique();

        // 3. Relationships (chi tiết xem Bước 13)

        // 4. Global query filter cho soft-delete
        modelBuilder.Entity<LineOperator>()
            .HasQueryFilter(e => !e.IsDeleted);
        // ... apply cho cả 10 entity
    }
}
```

BƯỚC 13: Program.cs - Khởi tạo & Dependency Injection
--------------------------------------------------------------------------------
File: Program.cs

```csharp
var builder = WebApplication.CreateBuilder(args);

// 1. Đọc connection string từ appsettings.json
var connectionString = builder.Configuration.GetConnectionString("DefaultConnection")
    ?? "server=localhost;port=3306;database=depotdb;user=root;password=root";

// 2. Đăng ký DbContext (Pomelo MySQL)
builder.Services.AddDbContext<DepotDbContext>(options =>
    options.UseMySql(connectionString, ServerVersion.AutoDetect(connectionString)));

// 3. Đăng ký Repository (Scoped - 1 instance / request)
builder.Services.AddScoped<IUnitOfWork, UnitOfWork>();

// 4. Đăng ký Service (Scoped)
builder.Services.AddScoped<IContainerService, ContainerService>();
builder.Services.AddScoped<IBlockService, BlockService>();
builder.Services.AddScoped<ILineOperatorService, LineOperatorService>();
builder.Services.AddScoped<ICustomerService, CustomerService>();
builder.Services.AddScoped<IContainerMovementService, ContainerMovementService>();
builder.Services.AddScoped<IReleaseOrderService, ReleaseOrderService>();

// 5. Đăng ký Singleton (DepotConfigManager, InMemoryCache)
builder.Services.AddSingleton<DepotConfigManager>(
    _ => DepotConfigManager.Instance);

var app = builder.Build();

// 6. Middleware pipeline
app.UseSwagger();
app.UseSwaggerUI();
app.UseStaticFiles();
app.UseRouting();
app.UseAuthorization();
app.MapControllers();
app.MapRazorPages();

// 7. Tự động tạo database + seed data khi start
using (var scope = app.Services.CreateScope())
{
    var context = scope.ServiceProvider.GetRequiredService<DepotDbContext>();
    context.Database.EnsureCreated();    // Tạo bảng nếu chưa có
    DbSeeder.Seed(context);              // Thêm dữ liệu mẫu
}

app.Run();
```

PHẦN 3: SƠ ĐỒ QUAN HỆ GIỮA CÁC ENTITY
================================================================================

Sơ đồ tổng quan (10 bảng):

   ┌─────────────────┐
   │  LineOperator   │  (Bảng cha: hãng khai thác)
   │  PK: id         │
   │  UQ: owner_code │
   └──┬──────────────┘
      │ 1
      │
      ├──────────────────────────────┐
      │ n                          │ n
      ▼                            ▼
   ┌─────────────────┐    ┌──────────────────┐
   │   Container     │    │  ReleaseOrder    │
   │   PK: id        │    │  PK: id          │
   │   UQ: container │    │  UQ: order_num   │

BẢNG TÓM TẮT QUAN HỆ:
----------------------------------------------------------------------
Quan hệ                                | Loại      | OnDelete
---------------------------------------|-----------|------------
LineOperator → Container               | 1 - n     | Restrict
LineOperator → ReleaseOrder            | 1 - n     | Restrict
Customer → ReleaseOrder                | 1 - n     | Restrict
ReleaseOrder → ReleaseOrderDetail      | 1 - n     | Cascade
ReleaseOrder → ContainerMovement       | 1 - n     | SetNull
Container → ContainerMovement          | 1 - n     | Cascade
Container → LineOperator               | n - 1     | Restrict
Container → CurrentBlock               | n - 1     | SetNull
Container → CurrentBay                 | n - 1     | SetNull
Container → CurrentRow                 | n - 1     | SetNull
Container → CurrentTier                | n - 1     | SetNull
Block → Bay                            | 1 - n     | Cascade
Block → Container (current)            | 1 - n     | SetNull
Bay → Row                              | 1 - n     | Cascade
Row → Tier                             | 1 - n     | Cascade
Tier → Container                       | 1 - 0..1  | SetNull
ContainerMovement → ToBlock            | n - 1     | SetNull
ContainerMovement → ReleaseOrder       | n - 1     | SetNull

GIẢI THÍCH CÁC LOẠI ONDELETE:
   - Cascade:  Xóa cha → tự động xóa luôn con.
               VD: Xóa Block → tự động xóa hết Bay → Row → Tier trong block đó.
   - Restrict: Có con → KHÔNG cho xóa cha. Phải xóa con trước.
               VD: Còn Container → không được xóa LineOperator.
   - SetNull:  Xóa cha → set FK của con thành NULL (giữ lại con).
               VD: Xóa Block → container vẫn còn, chỉ CurrentBlockId = null.

PHẦN 4: LUỒNG HOẠT ĐỘNG
================================================================================

LUỒNG 1: TẠO BLOCK MỚI (Physical)
-----------------------------------
1. POST /Blocks/Create → BlocksController.Create (Razor Page).
2. Tạo Block mới trong DB.
3. Nếu Block.BlockType = Physical → gọi BayFactory.CreateBaysForBlock:
   - Với mỗi bay từ 1 → MaxBays: tạo Bay (lẻ=Size20, chẵn=Size40).
   - Với mỗi bay: tạo MaxRows Row.
   - Với mỗi row: tạo MaxTiers Tier (IsOccupied=false).
4. Toàn bộ layout lưu vào DB trong 1 transaction.

LUỒNG 2: CONTAINER VÀO BÃI
-----------------------------
1. POST /Movements/Create với MovementType=In.
2. ContainerMovementService.CreateAsync:
   - Tạo 1 ContainerMovement (MovementType=In, ToBlockId=block đích).
   - Cập nhật Container: IsInYard=true, CurrentBlockId=ToBlockId.
   - CurrentBay/Row/Tier: set theo vị trí cụ thể trong block (nếu có).
   - Tier.IsOccupied=true, Tier.ContainerId=containerId.

LUỒNG 3: CONTAINER RA BÃI (theo lệnh giao)
--------------------------------------------
1. POST /api/release-orders/{id}/execute với containerId, vehicle.
2. ReleaseOrderService.ExecuteReleaseAsync:
   - Validate: ReleaseOrder.Status phải là New hoặc InProgress.
   - Validate: ValidUntil >= hôm nay.
   - Validate: Container.IsInYard = true.
   - Tạo 1 ContainerMovement (MovementType=Out, ReleaseOrderId=orderId).
   - Cập nhật Container: IsInYard=false, clear CurrentBlock/Bay/Row/Tier.
   - Cập nhật ReleaseOrderDetail.DeliveredQuantity++.
   - Nếu tất cả details đã giao đủ → ReleaseOrder.Status=Completed,
     ngược lại InProgress.

LUỒNG 4: TRUY VẤN CONTAINER THEO VỊ TRÍ
----------------------------------------
Query lấy tất cả container đang ở block X, bay Y:
   SELECT c.*
   FROM Containers c
   INNER JOIN Blocks b ON c.current_block_id = b.id
   LEFT JOIN Bays bay ON c.current_bay_id = bay.id
   WHERE c.is_deleted = false
     AND c.current_block_id = @BlockId
   ORDER BY bay.bay_number, c.current_row_id, c.current_tier_id;

Trong EF Core (LINQ):
   var containers = await _context.Containers
       .Include(c => c.CurrentBlock)
       .Include(c => c.CurrentBay)
       .Include(c => c.CurrentRow)
       .Include(c => c.CurrentTier)
       .Where(c => c.CurrentBlockId == blockId)
       .Where(c => !c.IsDeleted)
       .OrderBy(c => c.CurrentBay!.BayNumber)
       .ThenBy(c => c.CurrentRow!.RowNumber)
       .ThenBy(c => c.CurrentTier!.TierNumber)
       .ToListAsync();

TÓM TẮT NGUYÊN LÝ THIẾT KẾ
================================================================================

1. Repository Pattern (Generic + Specific):
   - IGenericRepository<T>: CRUD chung cho mọi entity.
   - Specific Repositories: thêm method riêng (vd: GetByContainerNumberAsync).
   - UnitOfWork: gom các repo + transaction.

2. Service Pattern (Business Logic):
   - Mỗi Service tương ứng 1 entity, có BaseService kế thừa để trả
     ApiResponse<T> thống nhất.
   - Service xử lý nghiệp vụ (validate, transaction, ...).

3. Soft Delete (Xóa mềm):
   - Repository.Remove chỉ set IsDeleted=true, KHÔNG xóa khỏi DB.
   - Global query filter (HasQueryFilter) tự động loại trừ khi truy vấn.
   - Muốn lấy cả bản ghi đã xóa: .IgnoreQueryFilters().

4. Singleton Pattern:
   - DepotConfigManager: cấu hình runtime (max tiers, rows, bays...).
   - InMemoryCache: cache trong bộ nhớ.
   - Dùng double-check locking + DI factory delegate.

5. Factory Pattern:
   - BayFactory: tạo bay với ContainerSize tự động (lẻ=20, chẵn=40).
   - ContainerFactory: tạo Container từ container number (ISO 6346).

6. Auto-migrate khi start:
   - Dùng context.Database.EnsureCreated() (KHÔNG dùng EF Migrations).
   - Mọi thay đổi schema cần xóa DB để apply lại.

7. Audit fields tự động:
   - CreatedAt: set khi AddAsync.
   - UpdatedAt: set khi Update / Remove (soft delete).
   - Tất cả do GenericRepository tự xử lý.
